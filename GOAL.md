# Installation Android Windows native

Installer et vérifier Android CLI, Android Studio stable, SDK/Build Tools/NDK stables actuels, Java JDK actuel et JDK compatible Android/Ghidra, Bun avec package Android, Rust avec packages Android et compilation native, outils RE Android et Ghidra avec clones GitHub officiels.

Le matériel et les données existants restent préservés. Aucun WSL.

Demande complémentaire : fusionner dans un seul monorepo `crates/`, `packages/`, `apps/`, avec Bun 1.4.4 réel, Cargo Rust nightly et FFI Java/Bun/Rust vérifiée.

Demande du 12 octobre 2026 : récupérer les références officielles récentes avec Context7 et GitHub, puis installer et intégrer Jetpack Compose, son runtime et les composants Material Design 3, avec versions vérifiées et bonnes pratiques appliquées.

Documentation complète par domaine dans `docs/rust`, `docs/bun`, `docs/java`, `docs/jetpack`, `docs/emu`, `docs/ui`, `docs/m3`, synchronisée automatiquement depuis les sources officielles par un script Bun complet. Les sources inaccessibles et les corpus partiels doivent être indiqués explicitement ; un échantillon ne prouve pas un corpus complet.
